# Scribble Power

A 10-week online writing craft series by **Scribble Ink** for Grades 4–9.

Display-ready HTML lessons with:

- **Skills Night** — ~5-minute craft drills
- **Under Pressure** — ~10-minute performance writes
- **Version A / B** on every screen (roughly 4–6 and 7–9)
- Built-in timer, coach notes, and expandable teacher demo space with sample solutions

## Curriculum map

| Week | Focus |
|------|--------|
| 1 | Open Strong — sentence starts |
| 2 | Cut the Fluff — stop words |
| 3 | Verbs That Move |
| 4 | Exact Colour — adjectives |
| 5 | Ban Very — intensifiers & limp adverbs |
| 6 | No Echo — repetition control |
| 7 | Word Power — vocabulary |
| 8 | Combine Craft |
| 9 | Edit Like a Pro |
| 10 | Showcase — capstone |

## Local

Open `index.html` in a browser, or:

```bash
cd ~/Desktop/online
python3 -m http.server 8080
```

Visit http://localhost:8080

## GitHub Pages (planomy/online)

Publish from **main** branch, folder **/ (root)**.

```bash
git remote add origin git@github.com:planomy/online.git
git push -u origin main
```

Site will be at `https://planomy.github.io/online/` once Pages is enabled.
