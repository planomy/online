# Scribble Power

A 10-week online writing craft series by **Scribble Ink**.

Display-ready HTML lessons with:

- **45-minute lessons** — 5-minute fun soaker + 40 minutes of work
- **Repeating craft lessons** — the same multi-skill drills and pressure writes every week
- **New theme each week** — students strengthen the same areas through fresh content
- **Skills Night** — soaker + eight ~5-minute craft drills
- **Under Pressure** — soaker + four ~10-minute performance writes
- **Champs + Legends** on every screen (side by side)
- Built-in timer, coach notes, and expandable teacher demo space with sample solutions

## Local

Open `index.html` in a browser, or:

```bash
cd ~/Desktop/online
python3 -m http.server 8080
```

Visit http://localhost:8080
